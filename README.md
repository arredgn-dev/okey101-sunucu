# 101 Okey online sunucusu

101 Okey uygulamasındaki "Online Oyna" ve "Salon seç" özelliklerinin bağlandığı oyun sunucusu.
Eşleştirme, masalar, taş dağıtımı, kurallar ve puanlama burada yürür. Ek paket gerektirmez (Node.js 18+).

Çalıştırmak: `node server.js` (port: `PORT` ortam değişkeni, varsayılan 8080)
Durum: `/durum`
